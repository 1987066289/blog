这篇文章展示一篇博客文章的标准写法，照着抄就能发新文章。

## 一、文件头部的信息区（front-matter）

每篇文章开头都有一段被 `---` 包起来的信息，最常用的只有标题和日期，其余可省略：

```yaml
---
title: 文章标题            # 必填：显示在列表和浏览器标签上
date: 2026-08-16 12:00:00  # 必填：发布时间
tags:                      # 可选：标签
  - 教程
categories:                # 可选：分类
  - 博客使用
cover: /img/xxx.jpg        # 可选：封面图（先放进 source/img/ 目录）
top: true                  # 可选：置顶（不置顶就删掉这行）
---
```

**最小可用版本**，只要三行就能发一篇文章：

```yaml
---
title: 我的第一篇文章
date: 2026-08-16 12:00:00
---
```

## 二、正文用 Markdown 写

### 常用语法速查

**加粗** 用两个星号包起来，*斜体* 用一个星号。

> 引用别人的话，用大于号开头

无序列表：

- 第一项
- 第二项
  - 缩进两格是子项

有序列表：

1. 第一步
2. 第二步

[链接文字](https://hexo.io) 用方括号加圆括号。

插入图片：先把图片上传到仓库 `source/img/` 目录，然后写
`![图片说明](/img/文件名.jpg)`

### 代码块

用三个反引号包起来，标注语言可以高亮：

```python
def hello():
    print("Hello, blog!")
```

### 表格

| 功能 | 写法 |
| ---- | ---- |
| 加粗 | `**文字**` |
| 斜体 | `*文字*` |
| 链接 | `[文字](网址)` |
| 引用 | `> 文字` |

## 三、草稿

还没写完、不想公开的文章：把文件放进 `source/_drafts/` 目录（没有就新建），构建时会被跳过。写完后挪回 `_posts/` 再加日期即可。
