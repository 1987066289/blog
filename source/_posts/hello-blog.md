欢迎来到我的个人博客！这是第一篇文章。

## 这个博客是怎么搭起来的

- **写作**：所有文章都是 Markdown 文件，放在仓库的 `source/_posts/` 目录下
- **生成**：使用 [Hexo](https://hexo.io/) 静态站点生成器 + [Butterfly](https://butterfly.js.org/) 主题
- **托管**：代码放在 GitHub，由腾讯 EdgeOne Pages 自动构建发布，全程免费

## 发一篇新文章有多简单

1. 在浏览器打开 GitHub 仓库，进入 `source/_posts/` 目录
2. 点「Add file → Create new file」，起个名字（如 `我的新文章.md`）
3. 顶部写上标题等信息，下面用 Markdown 写正文
4. 点「Commit changes」，等大约一分钟，博客就自动更新了

> 这篇文章本身就可以当模板参考——点开仓库里的 `source/_posts/hello-blog.md` 看看它是怎么写的。

## 试试这些功能

- 点右上角 🌙 切换**深色模式**
- 用搜索框**搜索文章**
- 看看右侧边栏的**分类和标签**
- 文章里的代码块可以**一键复制**：

```javascript
console.log('Hello, blog!');
```
